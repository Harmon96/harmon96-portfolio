# 직접 움직이는 3D 포트폴리오

2026-10-26. 기존 2열 썸네일과 요약 모달을 화면 전체를 사용하는 입체 작업 공간으로 교체했다. 밝은 배경, 무광 컬러 조형물, 큰 타이포그래피를 사용한다.

## 첫 화면

이름과 메뉴는 작게, WORK 타이포그래피와 네 개의 조형물은 크게 놓는다. 프로젝트마다 별도 사각형 배경을 두지 않으며, 작품은 서로 다른 거리·높이·각도로 배치한다. 조형물은 실제 회사 화면이나 성과 그래프가 아닌 이 포트폴리오를 위한 독립적인 시각 작업이다.

| 프로젝트 | 형태 |
| --- | --- |
| 해외 상품 직접구매 | 서로 얽힌 세 개의 파란 곡선 루프 |
| 배송·물류 | 두께와 단면이 있는 주황색 비정형 리본 |
| 의류 사입 커머스 | 앞면은 크림색, 뒷면은 먹색인 방사형 주름 셸 |
| FE 품질·관측 | 파란 안쪽과 중심이 드러나는 흑연색 구면 조각 |

홈의 작업 공간은 브라우저 전체 너비와 한 화면 높이를 사용한다. 소개·경력 본문은 그 아래에서 읽는다. 회사 경력의 실제 직무와 프로젝트 사실은 변경하지 않았다.

## 조작

- 빈 공간을 드래그하면 카메라의 시점이 달라진다. 놓으면 감속한 뒤 그 시점에 머문다. 휠은 일반 페이지 스크롤에 사용한다.
- 조형물이나 작업 이름을 선택하면 해당 작품으로 시점이 이동하고 다른 작품은 뒤로 물러난다. 큰 제목·설명·담당 역할·사례 링크는 같은 화면의 여백에 나타난다.
- 선택한 일반 작품은 드래그하거나 캔버스에 포커스한 뒤 방향키로 돌릴 수 있다. Home 키는 기본 방향으로 돌아간다.
- ‘전체 작업’ 또는 Escape로 이전의 전체 시점으로 돌아간다. 선택 목록의 포커스를 복구한다.
- ‘사례 읽기’는 기존 `/projects/<slug>/` 정적 주소로 이동한다. 상세 첫머리에도 같은 조형물을 직접 돌려볼 수 있다.
- 모바일에서는 가로 드래그로 둘러보고 탭으로 선택한다. 세로 스크롤과 핀치 확대를 유지하며, 작품 이름은 하단 선택 목록에서 읽는다.

## 실험

상단 ‘실험’을 선택하면 같은 공간이 두 작품으로 재구성된다.

1. **비틀어보기:** 주황색 띠를 가로로 드래그하거나 슬라이더로 변형한다. 입력 중 Escape·포인터 취소·탭 숨김으로 조작을 끝내도 실제 변형값과 슬라이더가 일치한다.
2. **글자 흩뜨리기:** 입체 PLAY 네 글자를 각각 잡아 옮긴다. 놓은 위치가 유지된다. 글자 선택 메뉴와 방향 버튼으로도 같은 배치를 조작할 수 있다.

‘처음으로’는 실험의 초기 상태를 복구한다. 실험은 3D 준비가 끝난 뒤 조작할 수 있다.

## 구현과 성능

React 19·TypeScript·Vite의 기존 정적 구조에 Three.js를 추가했다. 런타임 `three`와 개발용 `@types/three` 버전을 고정한다. Motion·외부 모델·추가 물리 엔진은 사용하지 않는다. @types/three가 요구하는 전이 개발 의존성은 lockfile에 함께 기록된다.

- `src/scene/sculptures.ts`: 외부 폰트·모델 없이 코드로 작성한 곡면과 입체 글자. 인스턴스별 리소스 정리.
- `src/scene/world.ts`: 카메라·선택·조작·조명·입체 레이블·렌더링 수명 주기.
- `src/content/spatial.ts`: 기존 사례와 연결된 형태·색·위치 정보. 실무 원고와 분리한다.
- 3D 모듈은 브라우저에서 지연 로딩한다. CSS는 클라이언트 진입점에서 가져와 서버 정적 렌더와 분리한다.
- 포인터 이동은 React 전체 렌더 대신 ref와 requestAnimationFrame으로 처리한다. 조작과 감속·시점 전환이 끝나면 렌더링을 멈추고, 숨겨진 탭에서도 중단한다.
- 픽셀 비율은 데스크톱 1.5, 터치 환경 1.25로 제한한다. 선택 상태에서는 그림자 범위를 좁혀 확대 시 표면 경계를 보완한다.
- 동작 감소 설정에서는 감속·카메라 보간을 생략한다. WebGL 초기화·context loss·렌더 실패는 읽을 수 있는 대체 화면으로 전환한다.

소개·요약·상세 링크와 사례 본문은 JavaScript 없이도 읽을 수 있다. 루트·GitHub Pages 저장소 하위 경로·직접 접근·새로고침을 지원한다.
