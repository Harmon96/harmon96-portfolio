로컬 Chrome 155.0.8059.86, 1440×900, headless 및 영상 기록 상태에서 140프레임을 측정했다. 중앙값 16.7ms, p95 16.8ms였다. 대기 350ms 동안 추가 drawElements 호출은 0회였다. 시점 yaw는 -0.0600에서 0.2600으로 바뀌어 유지됐고, 직접 잡아 옮긴 P 글자의 위치도 변경됐다. 페이지 오류는 수집되지 않았다. 원본은 `artifacts/spatial-review/metrics.json`이다. 이 수치를 실제 모바일 기기의 성능 보장으로 해석하지 않는다.

### 리뷰와 수정

- 첫 화면에서 맞닿던 파란 루프와 크림색 셸의 간격을 조정하고, 선택 상태의 그림자 범위를 좁혔다.
- 확대 시 다른 조형물이 설명과 겹치지 않게 했으며, 작은 모바일 뷰포트에서 작업 선택 후 조형물이 헤더 아래에 다시 나타나도록 정렬했다.
- 드래그 중단 시 변형값을 공통 종료 경로에서 동기화하고, 3D 준비 전에는 실험 조작을 제공하지 않는다.
- 홈과 상세 모두 캔버스 포커스·방향키·Home 키를 지원한다.
- 이전 스냅샷과 직접 비교했다. 실무 사례 데이터·경력 원고·라우팅·정적 빌드/프리뷰 스크립트는 byte-identical이다.
- 새 runtime은 three 0.186.1, 개발용 타입은 @types/three 0.186.0이다. 기존 패키지 버전은 변경하지 않았다.
- `npm audit --omit=dev --json`: 런타임 취약점 0건. 전체 감사의 개발 의존성 high 2건은 기존 vite 8.2.2/source-map-js 1.2.1이며 설치 전 스냅샷과 동일하다. 이번 범위에서 자동 수정하지 않았다.

### 건너뜀

- Safari: 현재 원격 자동화 설정이 꺼져 있어 WebDriver 세션을 만들 수 없었다. 시스템 설정은 변경하지 않았다.
- 설치된 이전 WebKit 바이너리로도 시도했으나 현 Playwright와 `Page.overrideSetting: Unknown setting: PushAPIEnabled` 프로토콜 오류가 발생했다. 엔진을 새로 설치하지 않았다.
- 실제 iOS·Android 기기, Firefox, 공개 호스팅 배포는 실행하지 않았다.

### 남은 위험

새 WebGL 구현의 Safari·실제 모바일 GPU 호환성과 공개 배포 환경은 미확인이다. JavaScript/WebGL 실패 시 읽기 경로는 Chrome에서 검증했다. GPU와 기기에 따라 3D 성능이 달라질 수 있으며 측정치는 위 로컬 환경에 한정한다.
